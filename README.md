# 🌍 Air Quality EDA

Exploratory Data Analysis (EDA) project focused on understanding **air quality trends, pollutant levels, and relationships between different environmental factors**.

## 📌 Objectives

* Analyze air quality and pollutant distributions
* Identify trends and patterns in the dataset
* Study relationships between pollutants
* Detect missing values and outliers
* Visualize key insights using charts and graphs

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Analysis Performed

* Data cleaning & preprocessing
* Descriptive statistics
* Univariate & bivariate analysis
* Correlation analysis
* Trend analysis
* Data visualization

## 📁 Project Structure

```text
Air-Quality-EDA/
│
├── Air_Quality_EDA.ipynb
├── dataset.csv
└── README.md
```

## 🚀 How to Run

1. Clone the repository
2. Install the required Python libraries
3. Open `Air_Quality_EDA.ipynb` in Jupyter Notebook
4. Run the cells to reproduce the analysis

## 📈 Key Outcome

The analysis provides insights into **pollutant patterns, air-quality variations, and correlations between environmental variables**.
